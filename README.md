# Calculator Application 🧮

A simple Java-based console application to perform basic arithmetic calculations. This project helps beginners understand core Java concepts and mathematical operations.

## 🚀 Features
* Perform Addition
* Perform Subtraction
* Perform Multiplication
* Perform Division
* User-friendly console interaction

## 🧠 Concepts Used
* **Java Programming:** Core application logic and execution.
* **Object-Oriented Programming (OOP):**
  * **Encapsulation:** Organizing calculation methods efficiently.
  * **Abstraction:** Simplifying arithmetic operations for users.
  * **Methods & Classes:** Structuring reusable calculator functionalities.

## 🛠️ How to Run
1. Clone this repository or download the `CalculatorApp.java` file.
2. Open your terminal or command prompt.
3. Compile the Java file:
   ```bash
   javac CalculatorApp.java
   ```

4. Run the program:
   ```bash
   java CalculatorApp
   ```
